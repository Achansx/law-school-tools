# Section VI. Prompting as Pedagogical Design

## 6.1 Qian's typology and the vault as process-based prompting (130 words)

- Claim: Yufeng Qian's systematic review of prompt engineering in education distinguishes technique-based strategies (single-ask patterns like role-prompting, few-shot, chain-of-thought) from process-based strategies (multi-step workflows where each prompt is one move in a longer pedagogical loop); the vault's prompt library is process-based in Qian's sense, because no single prompt produces a finished artifact and the pedagogical work happens across the rotation (Ingest, Lint, Enrich, Expand, Synthesize, Verify) rather than inside any one prompt. Evidence: evidence-06-qian-prompt-typology. Inferential move: this is the framing claim that licenses Section VI to treat the prompt library as a pedagogical artifact rather than a technical one and sets up Section VII's iteration argument; per L-024 the Cite phase should add a transfer clause when the prose lands the citation so the K-12-and-general-higher-ed scope of Qian's review is not silently imported as a law-school claim. [evidence: evidence-06-qian-prompt-typology]

## 6.2 The typed schema is the prompt (170 words)

- Claim: the Case Brief template (eighteen frontmatter fields plus the holding-bar, citation-meta, and authority-lineage blocks; nine fixed H2 sections in fixed order from Memory Jogger through Sources) is loaded into every Ingest and Enrich run as the prompt contract; the model is not asked to write a brief about a case in whatever shape it prefers, but to fill the typed scaffold. Evidence: evidence-06-typed-schema-as-prompt. Inferential move: Section V described the same schema as machine-readable substrate for an AI-authored note; Section VI reframes the schema as the prompt's pedagogical commitment, because the nine-section sequence is the canonical law-school case-brief format and committing the prompt to that sequence forces the generated brief to do the same analytical work a student is expected to do when briefing a case by hand. Per L-037 the dual classification of `Templates/` (vault-content for Section V framing, prompt-contract for Section VI framing) is the source of the reframing, not duplicate evidence. [evidence: evidence-06-typed-schema-as-prompt]

## 6.3 Prompts as pedagogical commitments: distribution, balance, depth (220 words)

- Claim: the Ingest prompt deliberately under-completes the case brief, populating only the factual sections plus a 150-word majority-only Analysis sketch and one Midpage-verified quotation, with every other section left as a one-line `<!-- ENRICH: -->` stub marker; the Ingest rubric's scope_discipline criterion mechanically scores down any brief written at full nine-section depth in a single pass, because finishing the brief in one pass starves the next phase of analytical work. Evidence: evidence-06-ingest-skeleton-prompt. Inferential move: the pedagogy is partly in what the prompt forbids, not only in what it asks for; Section VII develops the broader iteration argument that the under-completion is what produces analytical depth on the second and third reads. [evidence: evidence-06-ingest-skeleton-prompt]
- Claim: the Enrich prompt for Hypothetical Applications requires five hypos per brief in a fixed distribution (two same-side, two opposite-side, one fence-sitter), each with both a fact pattern and the reasoning that applies the rule; a hypo written as fact pattern alone scores zero for that slot. Evidence: evidence-06-enrich-hypotheticals-prompt. Inferential move: the distributional commitment encodes the law-school exam pedagogy of testing a rule against varying fact patterns at the prompt level, a pedagogical move that a hypothetical-set of any other shape would not produce. [evidence: evidence-06-enrich-hypotheticals-prompt]
- Claim: the Enrich Critique prompt requires at least one progressive angle and one originalist or textualist angle per enriched brief, each grounded in a published critique or a clearly signposted independent argument, with the rubric scoring 3 for missing one angle and 1 for missing both. Evidence: evidence-06-enrich-critique-balance-prompt. Inferential move: the two-angle requirement prevents the prompt from collapsing into whichever interpretive frame the model would default to and encodes the field's interpretive pluralism at the structural level; this is the prompt-design counterpart to the casebook tradition Section II describes. [evidence: evidence-06-enrich-critique-balance-prompt]
- Claim: the Synthesize prompt produces a Topic page in a fixed exam-ready scaffold (Governing Rule blockquote, Doctrinal Development, Key Cases table, the same five-hypothetical distribution Enrich uses, How to Spot on an Exam, Critique, Connections) with the exam_readiness rubric criterion weighted at 0.22 of the run score. Evidence: evidence-06-synthesize-exam-readiness-prompt. Inferential move: case briefs answer "what does this opinion hold" and Topic pages answer "what rule does the doctrine produce and how does a student deploy it on an exam"; the two prompts together implement the doctrine-first pedagogy Section III walks through from the user-experience side and Section X argues generalizes. [evidence: evidence-06-synthesize-exam-readiness-prompt]

## 6.4 Verification as pedagogy: Midpage discipline and adversarial reading (160 words)

- Claim: the Ingest and Enrich prompts both gate Key Quotations on Midpage verification, requiring confirmation against the indexed opinion rather than against the paraphrased PDF the professor distributed, with the rubric's midpage_verification criterion scoring the run at 1 if no new brief carries the verification; the Prize Cases / Justice Grier example documents what happens when the discipline lapses (a modernized PDF silently rewrote archaic phrasing, and an Ingest pass plus a Lint pass plus two Enrich passes plus an Expand pass all reproduced the modernized phrasing faithfully because none re-checked against the indexed text). Evidence: evidence-06-midpage-quote-verification-prompt. Inferential move: the prompt encodes a practitioner habit as a pedagogical commitment that is also a malpractice-avoidance commitment, which is the prompt-design counterpart to the malpractice frame Section XII develops with Mata v. Avianca. [evidence: evidence-06-midpage-quote-verification-prompt]
- Claim: the Verify prompt instantiates three adversarial personas (Staleness Auditor, Contradiction Hunter, Template Enforcer) with a three-row lead-rotation table and a four-row per-persona focus-mutation table both keyed off `state.verify_run_count`, and a forced-finding requirement that each persona return at least one finding per run or record `persona-produced-nothing` as its own finding. Evidence: evidence-06-verify-persona-prompts. Inferential move: adversarial reading is implemented at the prompt level rather than as an external review process, which mirrors moot-court and law-review-editor pedagogy where work is exposed to readers with different reading commitments rather than to a single generic reader; Section XII picks up the same architectural posture for the static-site-vs-chatbot risk argument. [evidence: evidence-06-verify-persona-prompts]

## 6.5 Compounding prompts: stub-marker handoffs and LESSONS as iteration memory (120 words)

- Claim: the `<!-- ENRICH: one-sentence description -->` stub markers are the prompt-to-prompt handoff convention; each Ingest skeleton carries a marker in every section it deliberately did not fill, the Ingest rubric's stub_markers_present criterion enforces the convention, and the Enrich rubric's stubs_resolved criterion (weighted at 0.22) measures the fraction of markers each Enrich run actually closed. Evidence: evidence-06-stub-marker-prompt-handoff. Inferential move: prompt design in the vault is at least as much about the handoffs between prompts as about any single prompt's wording, which is the structural feature that lets a long generation task decompose into smaller gradable sub-tasks. [evidence: evidence-06-stub-marker-prompt-handoff]
- Claim: LESSONS.md is the prompt-iteration memory file, with a fixed schema (Rule, Why, How to apply, Seen) capped at 35 entries and 60 words, loaded only by content-editing phases (Ingest, Enrich, Expand, Synthesize) and skipped by Lint and Verify, with examples including the em-dash typography rule, the no-invented-case-details rule, and the Learning Resources Inc v Trump amendment forbidding pre-filled Connections at Ingest. Evidence: evidence-06-lessons-as-prompt-iteration-memory. Inferential move: the prompt library compounds rather than restarts, which is the structural precondition for the Karpathy-loop iteration argument Section VII develops; the same architectural pattern reappears in Article/LESSONS.md, which is what makes the article's own method legible by the standard it describes. [evidence: evidence-06-lessons-as-prompt-iteration-memory]
