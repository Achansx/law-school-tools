Yufeng Qian's systematic review of prompt engineering in education distinguishes two families of prompting strategies: technique-based strategies (specific prompt patterns the user applies as a single ask, like role-prompting, few-shot prompting, chain-of-thought prompting) and process-based strategies (multi-step workflows in which the prompt is one move in a longer pedagogical loop, like iterative refinement, scaffolded inquiry, peer-review prompts). Section VI uses this distinction as its organizing frame: the vault's prompt library is a process-based strategy in Qian's sense, not a technique-based one. The case-brief prompt does not produce the brief in a single ask; it sits inside a six-phase rotation (Ingest, Lint, Enrich, Expand, Synthesize, Verify) where each phase's prompt depends on the prior phase's output, and the pedagogical work happens across the rotation rather than inside any one prompt.
