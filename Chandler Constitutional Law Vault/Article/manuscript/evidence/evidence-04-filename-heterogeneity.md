The Canvas export does not enforce a filename convention. Within a single 127-file top-level folder, the same kind of artifact (a lecture slide deck) appears under many filename shapes. Representative sample, drawn directly from `ls Source Materials/` on 2026-05-15:

- 11th Amendment.pptx
- Architecture_of_Exclusion.pptx
- Beyond mudflaps.pptx
- Biden_v_Nebraska_Standing.pptx
- Commandeering_Condensed.pptx
- Commerce_Clause_IQS_Review_slides.pptx
- Dormant_Commerce_Clause_Internet_Regulation.pptx
- Enumerated Powers- Warren Court and Beyond (2026).pptx
- Federalist Papers 2025.pptx
- Gibbons v. Ogden.pptx
- Hans_v_Louisiana_Lecture.pptx

Hyphens, underscores, spaces, parenthetical years, and dotted abbreviations appear in arbitrary combinations within the same folder. Some filenames encode topic, some encode case name, some encode year. There is no organization beyond the filename string itself. This is the surface that Section V's schema layer is built to translate from.
