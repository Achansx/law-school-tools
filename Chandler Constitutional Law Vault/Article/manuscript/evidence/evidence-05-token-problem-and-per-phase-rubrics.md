The vault's per-phase rubric architecture and tiered file loading were forced by a token-cost problem the system actually encountered. Early runs loaded a single large RUBRIC.md covering all six phases, the full LESSONS.md, the entire build narrative, plus whatever files the current phase needed. A Lint run that cared only about structural formatting was burning context reading Enrich and Verify criteria it would never use; a no-op Enrich run was still scoring itself against a rubric that did not apply. The fix was structural: split the rubric into six per-phase files, skip LESSONS for phases that do not need it, rotate the build narrative monthly so the file a run loads stays bounded, and log no-op phases as one-line entries rather than scoring them. The per-phase split also closed a secondary problem in which a phase could game a shared scoring criterion. Section V should describe this as the lived demonstration that the vault's schema is not architectural decoration; the structure was forced by what made the system work.

Exact source quote, `Chandler Constitutional Law Vault/archive/vault-blog-post-draft.md` "The token problem" section:

> Early runs were expensive in a way that was not obvious at first. The system was loading everything every run: a single large RUBRIC.md covering all six phases, the full LESSONS.md, the entire build narrative, plus whatever files the current phase needed to process. A Lint run that only cares about structural formatting was burning context reading Enrich and Verify rubric criteria it would never use. A no-op Enrich run (nothing to enrich, corpus already caught up) was still loading the full lessons file, scoring itself, and appending to the narrative before concluding it had nothing to do.
>
> The fix was tiered loading. The RUBRIC.md was split into six per-phase files, so a Lint run loads only lint.md. The LESSONS.md is now skipped entirely by Lint and Verify unless a specific persona needs it. The build narrative rotates monthly so the file a run has to read stays bounded. And no-op phases stopped being scored at all: if Enrich has nothing to enrich, it logs one line and moves on rather than running a full scoring pass against a rubric that does not apply. The per-phase rubric split also fixed a secondary problem where a phase could game a shared scoring criterion in a way that made its own number look good while making another phase's job harder.
