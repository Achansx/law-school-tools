# Rubric: Cite

Score each criterion 1 to 5.

## 1. Coverage

- 1: Many claims still lack footnotes.
- 3: Most claims cited; some orphans remain.
- 5: Every factual claim, statistic, quotation, and attributed argument has a footnote.

## 2. Bluebook form

- 1: Citation form clearly wrong (wrong reporter, missing year, mis-italicized signals).
- 3: Mostly correct, with stylistic inconsistencies.
- 5: Bluebook 21st throughout, including signals, parentheticals, and pin cites where the claim is page-specific.

## 3. URL liveness

- 1: Web sources cited without URL checks.
- 3: URLs included, not all verified.
- 5: Every web URL verified live in this run; dead URLs replaced with archive.org captures.

## 4. Primary-source discipline

- 1: Citations point to summaries or write-ups rather than primary sources.
- 3: Mostly primary sources; some secondary stand-ins remain.
- 5: Every citation points to a primary source (judicial opinion, original paper, original post). Secondary sources used only as context, never as authority.

## 5. Internal-cite hygiene

- 1: Internal logs, personal communications, or vault paths appear as citations in published prose.
- 3: Some internal cites moved to appendix; some still in prose.
- 5: Zero internal-source citations in published prose. Internal facts either re-supported with public sources or moved to appendix.
